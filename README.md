# Brightloop – Subscription Management System

## About the Project
Brightloop is an Odoo-based subscription management platform designed to automate subscription plans, customer management, recurring billing, invoicing, payments and revenue analytics.

## Problem Statement
Businesses often manage subscriptions, renewals, invoices and payments manually, resulting in missed renewals, billing errors and poor revenue visibility.

## Objectives
- Automate subscription lifecycle management.
- Manage products and recurring plans.
- Generate invoices automatically.
- Track payments and overdue invoices.
- Manage discounts and taxes.
- Provide real-time revenue analytics.

## Technology Stack
- Odoo
- Python
- PostgreSQL
- XML
- HTML, CSS and JavaScript
- Git and GitHub

## Main Modules
1. Authentication and User Management
2. Product Management
3. Subscription Plan Management
4. Quotation and Subscription Management
5. Invoice Management
6. Discount Management
7. Payment Management
8. Reports and Analytics
